## 🔧 **CUSTOMIZATION**

### Change Colors
Edit: `style.css` `:root` variables
```css
:root {
  --primary: #7c3aed;
  --secondary: #ec4899;
  /* Update any color here */
}
```

### Adjust Animations
Edit: `style.css` animation sections
```css
@keyframes float {
  /* Modify animation timing here */
}
```

### Modify Gradients
Edit: `style.css` gradient definitions
```css
--gradient-1: linear-gradient(135deg, #7c3aed 0%, #5b21b6 100%);
```
