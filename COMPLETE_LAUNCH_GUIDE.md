## CONTENT PASTE QUICK REFERENCE

### To Add Content to WordPress:

1. **Log In**: http://localhost/uptownfitness/wp-admin/
2. **Create Page**: Pages → Add New
3. **Add Title**: Enter page title
4. **Add Content**: Use Block Editor
   - Click "+" to add blocks
   - Add Heading, Paragraph, Button blocks
   - Format with proper structure
5. **Add Image**: Featured Image → Select/Upload
6. **SEO Optimize**: Yoast SEO box
   - Set focus keyword
   - Write meta description
   - Check readability
7. **Publish**: Click Publish button

### Block Editor Tips:
- Use Heading block (H1, H2, H3)
- Use Paragraph block for text
- Use Button block for CTAs
- Use List block for bullet points
- Use Column block for side-by-side content
- Use Gallery block for multiple images
