Getting Started
===============

1. Install WordPress if not already installed
2. Activate the Uptown Fitness theme
3. Create navigation menu with main pages
4. Customize colors in style.css (lines 7-14)
5. Add your logo via Appearance → Customize
6. Create pages and content using templates

Customization
=============

Colors:
  Edit /wp-content/themes/uptown-fitness/style.css
  Lines 7-14: Update CSS variables

Fonts:
  Edit /wp-content/themes/uptown-fitness/functions.php
  Update Google Fonts import URL

Logo:
  Appearance → Customize → Site Identity

Social Links:
  Edit /wp-content/themes/uptown-fitness/footer.php

Contact Info:
  Edit /wp-content/themes/uptown-fitness/footer.php

File Structure
