## HOW TO CREATE PAGES IN WORDPRESS

### Step 1: Access WordPress Admin
1. Go to: `http://localhost/uptownfitness/wp-admin/`
2. Log in with your admin account

### Step 2: Create a New Page
1. Click **Pages** in left sidebar
2. Click **Add New**
3. Fill in:
   - **Title**: Page title
   - **URL slug**: Keep URL-friendly (lowercase, hyphens)
   - **Content**: Paste the content provided
   - **Featured Image**: Upload royalty-free image
   - **Excerpt**: Short description (meta description)

### Step 3: SEO Optimization (with Yoast SEO plugin)
1. Scroll down to **Yoast SEO** box
2. Set **Focus Keyword**: Main keyword for page
3. Write **Meta Description**: 160 characters
4. Ensure **Readability** is green
5. Check **Keyphrase Distribution**

### Step 4: Publish
1. Click **Publish** button
2. Share permalink

## SEO BEST PRACTICES FOR EACH PAGE

### Heading Structure
- Use ONE H1 per page (the page title)
- Use H2 for main sections
- Use H3 for subsections
- Never skip heading levels (don't jump from H1 to H3)

### Keyword Optimization
- Natural keyword placement (1-2 per 100 words)
- Include in: H1, first paragraph, H2s
- Don't keyword stuff (avoid repetition)
- Use long-tail keywords naturally

### Meta Descriptions
- Always write custom meta descriptions
- 155-160 characters
- Include main keyword
- Include call-to-action when possible
- Make it compelling to increase clicks

### Internal Linking
- Link to related pages
- Use descriptive anchor text
- 2-4 internal links per page is optimal
- Link from high-authority pages to newer pages

### Content Length
- Homepage: 500-1000 words
- Service pages: 800-1500 words
- Blog posts: 1000-2000 words
- About pages: 500-1000 words
- FAQ: 1500-2000 words

## IMAGE SIZES & OPTIMIZATION

### Recommended Sizes
```
Hero images:      1920 x 600px
Service images:   600 x 400px
Trainer photos:   500 x 500px
Blog headers:     1200 x 600px
Gallery images:   800 x 600px
Thumbnails:       300 x 300px
```

### Image Optimization Before Upload
1. Use TinyPNG.com (free online)
2. Or use ImageOptim (Mac app)
3. Or install WP Smush plugin (auto-compresses)

### Image Upload Best Practices
1. **Filename**: Use descriptive names (personal-trainer-john.jpg)
2. **Alt Text**: Always add alt text for SEO
3. **Title**: Add image title
4. **Caption**: Optional but helpful
5. **Description**: Can add more details

## BLOG POST CREATION PROCESS

### For Each Blog Post:

1. **Create Post**
   - Go to Posts → Add New
   - Title: Compelling, keyword-rich
   - Content: Well-formatted with headings
   - Featured Image: Add header image

2. **Optimize for SEO**
   - Meta description (160 chars)
   - Focus keyword
   - Readability check
   - Add internal links (2-4)

3. **Categorize**
   - Assign at least one category
   - Add relevant tags

4. **Publish**
   - Set publish date
   - Publish or Schedule

### Blog Post Structure
```
Introduction (2-3 sentences)
↓
Main Heading (H1)
↓
Why This Matters (H2 section)
↓
Key Point 1 (H2)
  - Subsection (H3)
  - Details
↓
Key Point 2 (H2)
  - Subsection (H3)
  - Details
↓
Key Point 3 (H2)
  - Subsection (H3)
  - Details
↓
Conclusion (H2)
↓
Call-to-Action (Button or link)
```

## HELPFUL WORDPRESS TIPS

### Keyboard Shortcuts
- Ctrl+S (Cmd+S Mac) - Save draft
- Ctrl+K (Cmd+K Mac) - Add link
- Alt+Shift+H - Heading
- Alt+Shift+U - Bullet list

### Editor Tips
- Use Blocks for flexible layout
- Add Buttons block for CTAs
- Use Columns block for side-by-side content
- Add Gallery block for multiple images

### SEO Plugin Tips (Yoast)
- Green light means good optimization
- Fix all red issues before publishing
- Check readability score
- Optimize for featured snippets

### Publishing Tips
- Schedule posts for consistency
- Use SEO-friendly URLs
- Enable comments for engagement
- Add posts to category/tags
